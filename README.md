# 丫丫状态

macOS 桌面悬浮任务板。应用启动后显示在普通窗口上方，跨桌面空间保留，拖动空白处可移动位置，点击任务可跳回原工作台。

## 当前版本

- **已接入 Codex**：显示最近任务的工作中、已完成、已中断、报错或状态未知；点击任务使用 `codex://threads/<id>` 跳转。
- 显示 Codex 的五小时和每周剩余额度（如果 Codex 服务返回这些数据）。
- 悬浮框不会因鼠标移开或切换应用而消失；关闭与重新显示入口在菜单栏。
- 保存悬浮框位置。任务列表约每 2 秒（有运行任务）或 15 秒（无运行任务）刷新。
- 只读访问 Codex 的 `app-server` 和本地 `thread_history_*.sqlite` 状态索引；不读取任务消息正文。

“状态未知”表示当前没有足够的本地状态证据。它不会被当作“已完成”。Codex 现有状态索引无法可靠区分运行中和等待用户操作，因此本版暂不单独显示“待确认”。

## 运行

需要 macOS 13 或更高版本，以及已安装并登录的 Codex Desktop 或 Codex CLI。

```sh
./scripts/build-app.sh
open "dist/丫丫状态.app"
```

构建出的应用在 `dist/丫丫状态.app`。若只需从源码调试，可运行 `swift build`，但建议使用 `.app` 以获得正确的应用名称和菜单栏行为。应用当前采用本机临时签名，未做 Apple 公证。

## 后续工作台

任务展示采用 `TaskCollectionStore` + `MonitoredTask`。每个接入器需要提供来源、稳定任务 ID、标题、状态、更新时间和可选的原会话链接。来源不支持精确状态时必须报告“状态未知”，不能从进程存活或静默时间推断“任务已完成”。

见 [开源项目与接入评估](docs/接入评估.md)。
