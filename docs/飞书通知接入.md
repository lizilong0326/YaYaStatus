# 飞书完成提醒接入指南

飞书提醒是可选功能，首次安装默认关闭。丫丫状态在本机观察任务状态，通过本机安装的 `feishu-cli`，用你配置的飞书机器人给当前登录的飞书账号发私聊文本消息。应用不会附带机器人凭证，也不会把你的凭证上传到本项目。

## 1. 安装飞书 CLI

按照 [feishu-cli 的安装说明](https://github.com/riba2534/feishu-cli#安装)安装 macOS 版本，然后在终端检查：

```sh
feishu-cli --version
```

丫丫状态会在 `~/.local/bin`、`/opt/homebrew/bin`、`/usr/local/bin` 和应用进程的 `PATH` 中查找 `feishu-cli`。CLI 是可选依赖，不包含在丫丫状态的应用包里。

## 2. 配置你自己的机器人应用

已有可发送消息的飞书应用时，可以按 [feishu-cli 配置说明](https://github.com/riba2534/feishu-cli#配置凭证)配置它。新建应用可使用 CLI 的创建流程：

```sh
feishu-cli config create-app --save
```

在飞书开放平台为该应用启用机器人能力，并开通应用权限 `im:message:send_as_bot`。根据所在组织的管理规则，可能还需要管理员批准、发布应用或调整可用范围。将 App ID、App Secret 留在本机 CLI 配置中；不要提交到 GitHub。

## 3. 登录接收提醒的账号

在终端执行：

```sh
feishu-cli auth login
feishu-cli auth status
```

使用**希望收到提醒的飞书账号**完成授权。丫丫状态会用这个账号的 User Token 读取其 `open_id`，再让本机配置的机器人向该 `open_id` 发送消息。如果电脑里配置了多个 CLI Profile，应用使用 CLI 当前生效的 Profile；可用 `feishu-cli profile current` 核对。应用不会让你在任务列表中输入其他人的接收者 ID。

## 4. 在丫丫状态中开启

1. 打开丫丫状态，点齿轮进入设置，开启“飞书完成提醒”总开关。
2. 点击“发送测试”，确认飞书里收到测试消息；设置页会显示发送结果或错误。
3. 返回任务列表，只为需要提醒的**进行中**任务点亮铃铛。空心铃铛表示未选中，实心铃铛表示已选中；再点一次可取消。

总开关关闭后会立即清除所有已选任务，后续任务完成不会自动发送。重新开启时需要重新选择任务。应用重启后也需要重新选择。测试按钮只在总开关开启时可用。

## 何时发送、发送什么

丫丫状态保持运行，并观察到**已选中的同一任务**从“工作中”或“等待操作”变为“已完成”时，发送一条包含来源和任务标题的文本消息。历史完成任务不会补发；任务消失、连接失效、报错或以其他状态结束时不发送。任务标题可能含有私人信息，选择铃铛前请留意。

每次完成事件使用固定的幂等键，避免同一次事件重试时产生重复消息。收到非空 `message_id` 才视为发送成功。

## 排查

| 现象 | 检查 |
| --- | --- |
| 设置页提示找不到 `feishu-cli` | 确认 CLI 已安装在上面列出的目录或应用进程的 `PATH` 中。 |
| 测试发送失败，提示账号或权限问题 | 核对当前 CLI Profile、登录状态、机器人能力和 `im:message:send_as_bot` 权限；按 CLI 返回的具体错误补足授权。 |
| 测试消息发到了别的账号 | 用 `feishu-cli profile current` 和 `feishu-cli auth status` 核对当前账号；应用始终发给当前登录账号。 |
| 测试成功，但任务完成后没收到 | 确认总开关仍开启、该任务的铃铛已点亮、丫丫状态仍在运行，而且来源确实报告了“已完成”状态。 |

`feishu-cli` 的安装、应用创建和授权流程可能更新；命令细节以[上游项目说明](https://github.com/riba2534/feishu-cli)为准。
